How to read this model

Pink particles are positively charged protons, gold particles are neutral neutrons, and cyan particles are negatively charged electrons. The isotope selector changes neutrons, not the element itself. The orbital paths and relative sizes are artistic simplifications.

ATOMIC DATA: element names, atomic weights and reference isotopes supplied from RDKit's periodic table; shell diagrams use a simplified filling model and selected known exceptions. This is an educational illustration, not an actual photograph or a physically accurate depiction of electron motion. Some configurations for the heaviest elements are theoretical.
